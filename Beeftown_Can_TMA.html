Beeftown Cân TMA

Cài hàng cho cân TMA

Sửa tên hàng, giá và chữ trên tem ngay trên máy tính, rồi nạp vào cân bằng USB. Mọi thứ xử lý trong trình duyệt, không gửi dữ liệu đi đâu.

  1. Lưu dữ liệu từ cân ra USB

    Cắm USB vào cân, bấm Prog, ↓ V3 tới P4, Accu/Confirm, Accu/Confirm, rồi Amend. Chờ cân lưu xong, bấm Sale.

  2. Mở file và sửa ở đây

    Chọn file JHSCALE/A_000.TMS trong USB. Sửa hàng, giá, chữ trên tem rồi bấm Tải file.

  3. Nạp lại vào cân

    Chép file mới vào USB, thư mục JHSCALE, chọn Thay thế. Cắm vào cân: Prog, ↓ V3 tới P4, Accu/Confirm, Accu/Confirm. Nạp xong rút USB ra.

Mở file từ cân

Kéo file A_000.TMS vào đây File nằm trong thư mục JHSCALE của USB, sau bước 1.
Đang hiện dữ liệu ví dụ của Beeftown. Mở file từ cân để sửa thật.

    Xuất file cho cân

    Sửa các lỗi sau trước khi tải file:

      Lưu ý khi dùng cân

      • Không để USB cắm sẵn lúc bật cân: cân sẽ tự nạp file A_000.TMS có trong USB.
      • Trong menu Prog, không vào P3 › Delete và P5 › Hardware Asst. Cân hỏi mã 9958 nghĩa là sắp xoá dữ liệu: bấm Cancel.
      • Giữ một bản file gốc lưu từ cân trên máy tính, không để trong USB. Nạp lại bản đó là cân về như cũ.
      • Nếu có người sửa hàng trực tiếp trên cân, lưu file mới từ cân (bước 1) trước khi sửa ở đây.
